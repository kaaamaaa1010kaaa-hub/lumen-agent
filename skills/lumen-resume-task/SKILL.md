# 作業を再開する

直前のアシスタントのターンに `<task_queue goal="...">…</task_queue>` があれば、それは前回の作業計画の状態。✓ = 完了、✗ = 失敗、… = 実行中、・ = 未着手。

1. 新しい依頼と取り違えて、ゼロから計画し直さない。未完了（・と …）を引き継ぎ、完了（✓）は再実行しない。
2. 失敗（✗）は、同じ方法の繰り返しにしない。失敗の理由を踏まえて、次の一手を変える。
3. 「何をしていたか思い出せない」ような素振りや、改めての確認は不要。「前回の続きから、〜を行います」と、地続きの作業として始める。
4. task_queue が無い、または全て ✓ のときは、直前の回答の続き（説明の続き、次に取り組む自然な作業）と解釈する。「続きが見当たりません」と返して止まらない。続けるべき作業が本当に推測できないときだけ、何を続けたいかを一言で聞く。
